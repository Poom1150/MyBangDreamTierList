# Character pictures for the ID card

This folder is empty on purpose: the site does not ship any official character artwork.

If you want a picture to appear automatically when someone picks a character as their main, add your own image here,
named after the character id below, as `.webp` or `.png` (a transparent background looks best, about 600 px tall):

    assets/characters/<character id>.webp

For example `assets/characters/popipa-toyama-kasumi.webp`. Visitors can also upload their own picture on the ID card page, which always wins.
