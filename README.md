# MyBangDreamTierList

A small static site for ranking your ten favorite BanG Dream! original songs. First place gets the biggest cover, and the board can be saved as a PNG or shared as a link.

## Features
- 10 ranks arranged as a pyramid: #1 is the largest, then #2-3, #4-6 and #7-10.
- Browse about 490 original songs by band, or search by title (press `/` to jump to search).
- Tap a song to place it, tap a rank first to choose where it goes, or drag to reorder.
- Save the board as an image, or copy a share link (the ranking is stored in the URL hash).
- Your ranking is remembered in the browser (`localStorage`).

## Run locally
The page loads JSON with `fetch()`, so it needs a web server (opening `index.html` as a file will not work):

```
python -m http.server 8000
```

Then open http://localhost:8000.

## Layout
| Path | What it is |
|---|---|
| `index.html`, `styles/`, `scripts/` | The site (`scripts/poster.js` draws the exported image) |
| `data/songs.json`, `data/bands.json` | Song and band lists, generated by `build_data.py` |
| `covers/<Band>/` | Cover images. Most are WebP (max 800px). CHiSPA, Glitter Green, sumimi and Other & Collaborations are kept as the original files. |
| `covers/index.csv` | Where each cover came from (Bestdori game jacket, or a wiki fallback) |
| `assets/bands/` | Band icons from Bestdori |

To rebuild the data files after changing `covers/index.csv`, run `python build_data.py`.
