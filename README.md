# MyBangDreamTierList

A small static site with two modes: rank your ten favorite BanG Dream! original songs (first place gets the biggest cover), or pick the one song you like most from each band. Either board can be saved as a PNG or shared as a link.

## Features
- **Top 10 ranking:** 10 ranks arranged as a pyramid: #1 is the largest, then #2-3, #4-6 and #7-10.
- **Best song per band:** one pick for each of the 12 bands; the saved image shows each band's logo next to its song.
- Browse about 450 original songs by band, or search by title (press `/` to jump to search).
- Tap a song to place it, tap a rank first to choose where it goes, or drag to reorder.
- Save the board as a vertical 1080x1350 image (sized for a Facebook post), or copy a share link (the picks are stored in the URL hash).
- Your ranking is remembered in the browser (`localStorage`).

## Run locally
The page loads JSON with `fetch()`, so it needs a web server (opening `index.html` as a file will not work):

```
python -m http.server 8000
```

Then open http://localhost:8000.

## Layout
| Path | What it is |
|---|---|
| `index.html`, `styles/`, `scripts/` | The site (`scripts/poster.js` draws the exported image) |
| `data/songs.json`, `data/bands.json` | Song and band lists, generated by `build_data.py` |
| `covers/<Band>/` | Cover images as WebP (max 800px) |
| `covers/index.csv` | Where each cover came from (Bestdori game jacket, or a wiki fallback) |
| `assets/bands/` | Band icons (Bestdori, plus a few picked by hand) |
| `assets/logos/` | Band wordmark logos from the BanG Dream! Wikia, used on the per-band image |

To rebuild the data files after changing `covers/index.csv`, run `python build_data.py`.
